# Writing Assistance for Raycast

A Raycast extension that brings the power of the OpenRouter API to your fingertips, offering a wide range of language models to assist with your writing and thinking.

## Features

*   **Ask:** Get quick answers to your questions.
*   **Chat:** Have a conversation with your chosen AI model.
*   **Improve Writing:** Refine your text for clarity, tone, and style.
*   **Summarize:** Condense long texts into key points.

## Setup Instructions

1.  **Get an OpenRouter API Key:**
    *   Go to [OpenRouter.ai](https://openrouter.ai/).
    *   Sign up or log in to your account.
    *   Navigate to the "Keys" section to create a new API key.

2.  **Add API Key to Raycast:**
    *   Open Raycast and go to the "Extensions" tab.
    *   Find the "Writing Assistance" extension and open its preferences.
    *   Paste your OpenRouter API key into the designated field.

## Usage Examples

*   **Brainstorming:** Use the "Ask" command to generate ideas for a blog post.
    > "Give me 5 blog post ideas about productivity."
*   **Refining an Email:** Use the "Improve Writing" command to make an email more professional.
    > "Improve this email: hey, can u send me the report when u have a chance. thx"
*   **Getting Quick Answers:** Use the "Ask" command to get a quick definition or explanation.
    > "What is the capital of Australia?"

### Selecting a Model

In any of the AI-powered commands, you can select a model from the dropdown menu located on the right side of the search bar. The dropdown menu is populated with the list of available models fetched directly from the OpenRouter API. The extension will remember your selection for future use.
